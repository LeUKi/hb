# 链接预览（OG 标签）

链接贴到社区、Telegram、QQ、Discord、X 时，对方程序抓页面的 HTML 做预览卡。它们不跑脚本，只读服务器给的 `<head>`。以前每个网址都是同一句“lafish的红包站”。

用户 2026-11-20 定的：先做第一步——按网址写文字标签，全站共用一张固定图；每个红包现画封面（第二步）以后看效果再定。

## 1 谁来写

网页 Worker（`apps/web/src/worker.ts`）。除了静态文件（`/assets/*`、`/sdk/*`、`/version.json`、`/og.png`），所有网址都先到 Worker：它取 `index.html`，把 `<!--page-meta-->` 和 `<!--/page-meta-->` 之间换成这个网址的标签，再交给浏览器。不是 HTML 的回答原样返回。

- 本地开发的配置（`apps/web/wrangler.jsonc`）还多放过三类路径：`/src/*`、`/@*`、`/node_modules/*`，这是 Vite 开发服务器自己的模块（2026-11-21）。它们原来也先到 Worker，每个模块请求都要另开一个本机连接，e2e 几组一起跑时本机端口被用光，测试成批假失败。Stage 和生产的配置不用加：构建后的文件都在 `/assets/` 下。几份 wrangler 配置都不写注释，所以原因记在这里。
- 标签和静态页面的文字在 `apps/web/src/lib/page-meta.ts`，构建时也用它写默认的那一套。
- 要读数据的页面问 API：`GET /api/site/preview/<类>/<键>`，只回 `{ title, description, tab }`。同一个网址的回答在边缘缓存 60 秒；1.5 秒没回或出错，就用全站通用的标签，页面照常打开。
- `<title>` 和页面自己设的一样（红包页是红包标题），打开后标签页的标题不会跳。

## 2 每个网址写什么

| 网址 | 预览标题 | 预览描述 |
|---|---|---|
| `/` | lafish的红包站 | 用 LINUX DO 账号登录，输入口令或打开红包链接领红包，也可以自己发红包。 |
| `/🧧/<码>` | 小满的红包 · 周末红包 | 口令红包 · 拼手气。打开链接，输入口令领取。 |
| `/🧧/<码>/🎲` | 开奖数据 · 周末红包（拼手气等为“发放数据”） | 怎样核对 |
| `/☕/<卡号>` | 卡上的话（没写就是“打赏 小满”） | @小满 的打赏卡，打开链接就能打赏。 |
| `/judges/<编号>` | 判定器名 · 判定器 | @作者 的判定器。它的简介；标了过时的先说“作者已把它标为过时”。 |
| `/points/<编号>` | 积分名 · 三方积分 | 它的介绍（介绍是 Markdown，只留显示出来的字）；没有就写谁发行的 |
| `/help`、`/help/*` | 各篇的标题 | 各篇的一句话 |
| `/rank`、`/square`、`/judges`、`/roadmap` | 页面标题 | 页面上的那句说明 |
| `/invite/<…>` | 🐟额 PLUS 邀请 | 有人邀请你开通🐟额 PLUS，打开链接登录后接受。不写是谁。 |

- **红包**：和内嵌图同一条规矩（[redesign/05](redesign/05-hongbao.md) §6）：不写口令、说明、附言、总额、每份、头像、谁领了。剩余份数和“进行中 / 已结束”也不写：预览卡会被对方缓存，社区的预览更是写进帖子里不再变，会变的数字很快就是错的。只写不会变的：谁发的、标题、怎么领。草稿也一样（开放后链接不变）。删了的、找不到的，用通用标签。
- **判定器**：只有在判定器广场上的（没被下架）才写；其余用通用标签，和没登录的人能看到的一致。
- **三方积分**：上线过的（上线、暂停、停用）才写；草稿和审核中的用通用标签。
- **打赏卡**：作者账号停用的，用通用标签。
- **帮助的问题链接**：`/help/claim#q-no-match` 预览的是所在的那一篇，`#` 后面的部分预览程序拿不到。

其余网址（我的、记录、🐟额、付款、商户、网站管理、红包的 📝📊🧾、打赏详情、`/🔑/…`、`/magic`、`/💬/…`、`/new` 和各种编辑页）只写通用标签，另加 `<meta name="robots" content="noindex">`，搜索引擎不收录。

## 3 图

`/og.png`，512 × 512：整张是红色方块的渐变，中间是金点（站点图标的样子，没有圆角，平台会自己裁圆角）。方图在各平台都是小缩略图，不会被放大成一整条横幅。`twitter:card` 用 `summary`。

图是按 `brand.ts` 的图标画好放进 `apps/web/public/` 的；换图标时重画一张。

## 5 不做的

- 不按访问者区分：爬虫和真人拿到同样的 HTML。
- 不提前刷新社区里已经生成的预览：旧帖要被编辑才会重新抓。
- 不做每个红包的封面图（第二步）。
