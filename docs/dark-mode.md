# 深色

红包站原来只有浅色（「夜灯」：深红的背景，窗口是白色的磨砂玻璃）。社区小程序和嵌在别处的打赏卡已经有一套深色（[小程序 §4](mini-app-design.md)、[打赏卡 §7](tip-design.md)），那篇写着“这套深色以后红包站也能用”。这一篇把它用到红包站本身。

## 1 什么时候是深色

- 默认跟随系统（`prefers-color-scheme`）。系统切换时，页面跟着变，不用刷新。
- 账号卡片（右上角头像，没登录时是“登录”）的最下面有「外观」：跟随系统、浅色、深色。选了浅色或深色就不再跟随系统。
- 选择存在这个浏览器里（`localStorage` 的 `hb.theme`；跟随系统就删掉这一项），别的标签页也跟着变。不存在账号上，换了浏览器要重新选。
- `index.html` 在第一次绘制之前就按同样的规则定下深浅，启动画面也是深色的，所以深色的人不会先看到一闪的浅色。
- 嵌在别处的打赏卡（`?embed`）不受影响，仍然看 `?theme`。

## 2 怎么实现

深色时 `<html>` 上有两个标记：

- `data-mode="dark"`：换掉共用的颜色（文字、填充、线、强调色、成功和错误、金色字），和小程序、打赏卡用的是同一组（`styles.css` 里 `:root[data-mode="dark"]`）。
- `data-site-dark`：只有红包站有。换掉红包站自己写死了白色的那些表面：窗口玻璃、面板、输入框、选项卡片、按钮、指令框、弹层和它后面的压暗层、顶栏、背景。小程序也引用 `styles.css`，但它的页面上没有这个标记，所以不受影响。

颜色：

- 背景还是那片深红，压得更暗，三盏灯也暗一些。
- 窗口是深色玻璃（`rgb(30 24 26 / 0.86)`，带一点暖色，放在红色上不显得发灰），模糊和高光边保留。
- 面板、输入框、次要按钮是白色加很低的透明度（4%–13%），和小程序一样。
- 红包皮的红和金、代码判定的黑漆不变。黑漆按钮在深色玻璃上加一条淡金色的细边，不然看不出边界。
- 金色底上的字（头像首字、金色标签、手气最佳）仍用深金色。
- 没有模糊（浏览器不支持，或系统要求降低透明度）时，和浅色一样换成不透明的表面，只是深色。

人机验证（Turnstile）跟着当前的深浅画。附带网页 `hb.ready()` 返回的 `theme` 是网页打开那一刻的深浅（[附带网页](judge-page-design.md)）。

代码：`apps/web/src/lib/theme.ts`（偏好、跟随系统、加标记），`components/shell/theme-switch.tsx`（「外观」），`styles.css` 最后一段，`index.html` 里的首屏脚本和启动画面。

## 3 检查过什么

2026-11-15，本地开发服，1280×860，Edge 无头模式，系统浅色和深色各一次：

- 首页、红包广场、排行榜、帮助、账号卡片（未登录）。
- 「外观」：选深色后标记和 `color-scheme` 立刻变深，刷新后在应用加载之前就是深色；选回跟随系统后存的选择被删掉，系统切到深色时页面跟着变。

没有看过的：登录后的页面（发红包、红包记录、🐟额、商户、网站管理）、有数据的红包页和它的弹窗、手机宽度、真机 Safari。这些页面里如果还有写死的白色，会在深色下显得突兀，要逐个补。
