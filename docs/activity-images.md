# 动态活动图片

本批采用用户确认的动态图片 Demo 样式，统一站内、原型与外部 SVG。最初交付为本地实现与验收，后续已获授权将图片地址改为 Emoji 活动链接的 `/live.svg` 子路径并部署。后续全量提交与部署已获授权并完成；推送和论坛发帖不在本次交付中。准确版本见本文末尾发布记录。

## 样式与状态

共享实现位于 `packages/contracts/src/activity-image.ts`，源自 `cloudflare-time-image-demo/src/red-packet.js`。保留 420×560 比例、原封套曲线、红色与金色、暖白结果纸 `#f6efdf`、绿色金额 `#168045`、粒子、1.8 秒开封，以及活动快照在 10／30／60 秒后的老化。每个内联实例隔离 SVG ID、类名与动画名。独立 SVG 图片默认播放动画，不读取系统减少动态效果偏好；静态后备和站内预览继续由调用方显式指定静态呈现。

首页未选活动时使用中性封套，无测试作者、库存、时间或金额。图片只表达事实；“开”“报名”不会隐式提交。已领取优先于结束；金额是分配额，`confirmed` 才显示“已发放”，不宣称实际到账。未知付款显示“正在核对原订单”。领取时间来自 `claims.claimed_at`。报名、开奖、未中奖独立表达，不使用假金额。数量遵守精确、模糊、可用性或隐藏规则，开奖不把未分配库存称作即时可领库存。

正式应用和原型中，已领取／已中奖红包每次实际进入活动页都完整播放约 1.8 秒开封，覆盖直达、整页刷新、历史列表及后退／前进重新进入。首页进入时先完成约 300ms 的共享移动，等待目标布局及身份/本人记录后再播放开封；后台刷新、名单关闭和同页弹窗历史不能重播。动画仅展示已有结果，不重复领取、报名或付款，也不改写领取时间和快照读取时间；减少动态效果时直接显示最终状态。退出、完整会话变化或权限错误撤下私人展示。名单、付款帮助与页面操作保持可访问 HTML，不放入外部 SVG。

## 图片与分享

- `GET /e/:emoji/live.svg`：读取已开放、未删除的 LDC 活动，支持 HEAD。Web Worker 将 Emoji 图片子路径转发至只读 API，分享链接统一使用此路径；旧 UUID 图片地址继续兼容。无需加入活动广场；草稿、删除和退役文本数据返回不可用。
- 图片链接不再生成或处理 `motion=reduced` 分支，旧参数按普通版本处理；`tz` 接受有效 IANA 时区；`fallback=public` 强制中性静态公开封面，不含个人状态、库存、领取或快照时间。URL 不接受作者、金额、领取时间、用户身份或跳转目标覆盖。
- 顶层文档导航按 Fetch Metadata 或浏览器的 `Accept: text/html` 跳转到该活动的站内地址；普通图片请求返回 SVG。错误也返回同款中性 SVG 和实际 404／500 状态。
- “分享活动 → 内嵌代码”提供公开内联预览、复制代码和图片链接。预览不请求图片接口，不记录浏览。代码用 `<center>` 包裹 `<picture>`，不添加 `<a>`；图片地址只放在唯一 source 的 srcset 中，img 仅保留 width、height 和 alt，不设置 src（包括空 src）或 srcset。根据用户的论坛实测反馈，此结构用于避开论坛通过 img.src 下载缓存图片的处理。系统减少动态效果设置不改变图片选择，浏览器只请求 source 指定的普通动态图片。代码中的 Emoji 保持可读，查询分隔符等仍执行必要的 HTML 属性转义。弹窗显式居中、内部滚动，只显示预览、代码及复制操作，不附加图片行为说明。
- 所有图片响应 `private, no-store`，CDN 同样不缓存，Vary 包含 Cookie 和导航请求头，不开放凭证 CORS。无 JS、外部资源或自动轮询。

内嵌代码不再提供后备图片地址；source 被清洗或不被支持时，没有替代图片请求。`fallback=public` 保留为既有图片接口的兼容能力，不用于生成内嵌代码。no-store 不能阻止论坛下载另存，也不能更新或擦除已经显示的图片。用户已反馈 img.src 会触发论坛缓存；本地浏览器验证不等同完整的 linux.do 清洗、代理和 CSP 验收。

## Cookie 生命周期

主 `hb_session` 保持 Lax。`__Host-hb_image_session` 使用 Secure、HttpOnly、SameSite=None、Path=/，无 Domain/Partitioned。现有 AES-GCM 加密绑定父会话哈希、原到期时间和配置来源，用途与其他密文隔离；不复制原会话令牌或 CSRF。正常登录及同源会话读取自动补发，不延长父会话。每张个人图片只读核验有效会话及 active 用户，主 Cookie 存在时优先；失效主身份不能回退旧图片身份。其他 API 不认可图片凭证。

跨站 Cookie 被阻止或分区隔离时，图片显示公开“查看”。SameSite=None 只允许浏览器考虑发送，不能绕过隐私策略；CHIPS 不能把本站顶层身份自动桥接至论坛。撤销对新的身份检查生效；外部已显示快照不可能远程擦除。

独立最近记录只含公开活动 ID 与服务端请求时间，最多 30 天，跨登录和换账号保留。有效期从请求开始计算，迟到响应不能延长它。仅成功动态 GET 记录，HEAD、文档跳转、错误、fallback 和内联预览不记录。清除另保留时间界限，使清除前迟到响应不可再次显示。新请求可产生新记录；并发以浏览器最后接受的记录为准，不宣称完整浏览历史。

账号页已移除整个“本浏览器图片设置”区域，包括时区选择、最近请求展示、刷新及清除入口。后端既有偏好与记录接口保留兼容，前端不再请求这些接口。最近请求与账号无关，可能来自预加载，不代表实际观看。时区仍为有效 Cookie > URL > Asia/Shanghai，不用 IP 推测。

账号接口：`GET /api/me/activity-images` 返回 `{timeZone,recentRequest}`；`PATCH` 同路径保存 `{timeZone}`；`DELETE /api/me/activity-images/recent-request` 清除记录。读取要求主会话；写入还要求精确 Origin 与 CSRF。只改 Cookie，不新增表或迁移。

## 数据与验证边界

图片使用 SQL 白名单，先过滤 LDC、未删除、已开放，再投影公开信息和当前用户事实。不得读取口令、私有说明、库存密文或付款诊断；不得调用业务恢复 GET、更新会话访问时间、生成尝试、运行开奖或唤醒 DO/Queue。全文隐私检查包含不可见 SVG 元素和属性。

站内公开快照和本人参与事实分别记录成功读取时间。领取、报名及付款状态使用对应参与记录的读取时间；缓存回填、失败重试、页面重绘和动画重播不重置时间。图片及兑奖相关缓存使用完整会话身份隔离；活动配置的原编号保存重试仍按既有账号规则继续，不因同账号会话刷新丢失配置提交。

定向验证入口：共享契约图片测试、API activity-images 测试、正式分享/账号/转场测试、原型分享/转场测试。`playwright.activity-images.config.ts` 使用临时自签证书的两个 HTTPS 站点（localhost 与 127.0.0.1），实际运行本地 Web/API/D1/DO/Queue 和隔离上游替身，覆盖三个浏览器及 Firefox 明确禁止第三方 Cookie 的设置。证书和数据库位于临时目录，退出删除；不读取部署密钥，不接触真实付款，不保存截图或 trace。

## SVG 红包总览

本地原型提供 [SVG 红包总览](http://127.0.0.1:4177/#svg-gallery)，也可从原型顶部同名链接进入。总览直接调用正式共享渲染器，集中对照基本状态、四种金额方式、付款进度、数量隐私、0／10／30／60 秒时效及长内容。样例使用本地数据，不读取账号、写 Cookie 或请求活动图片接口。

可按分类筛选、切换时区、减少动态效果和重播动画。圆形封印的单字及多字文案统一以圆心为文字中心；静态后备和开封中的封印也采用同一规则，避免较小字号仍使用“开”的固定基线而偏下。
