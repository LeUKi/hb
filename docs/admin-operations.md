# 管理员后台一期：只读运维与网站设置

状态：本地实现与验收已完成，用户随后授权部署；预发布与生产均已发布（2026-10-12）。用户已确认只读运维、付款仅查看、私有内容只看状态与关联、概览优先异常与积压。

## 页面与权限

主导航“管理”进入 `/admin`，子页为 `/admin/activities`、`/admin/users`、`/admin/payments`、`/admin/settings`、`/admin/audit`。旧 `/admin/rate-limits` 使用 replace 重定向到设置。固定 Linux DO ID 部署名单授权，每个管理员接口先执行 `requireAdmin`，响应 `no-store`；不增加动态角色管理。

六个入口沿用紧凑表格。活动、用户、付款详情为桌面侧栏／手机弹窗，关闭回焦入口，直接访问回焦搜索区域。搜索、筛选、游标和详情 ID 保存在 URL；记录只存会话内存。每页 20 条，创建时间和 ID 倒序，名称包含匹配（特殊字符按字面量），标识／订单号精确匹配。搜索按钮或 Enter 提交，条件改变回第一页，刷新保留条件和位置。

## 概览与列表

概览 30 秒可见更新，焦点／手动刷新合并在途请求。付款等待超过 1 小时、开奖结算超过 10 分钟、任务未投递超过 10 分钟、维护失败或超过 15 分钟未完成／未更新提示异常。未知结果与需要关注分开；正常发送／等待不算失败。真实与模拟分开展示。显示当前环境和真实付款／限时开奖许可及阻止原因，全部只读。维护每类仅最近记录，缺失“暂无运行记录”；Cloudflare 队列指标“未接入”，不以 outbox 代替队列。读失败保留旧成功内容，标记失败和上次读取时间。

活动包含所有未删除草稿／进行中／已结束／归档，软删除从列表、详情和统计排除，直访 404。按名称、UUID、本站 UUID／Emoji 活动链接、有效 Emoji 码、关联帖子检索，奖励类型、生命周期、开奖异常筛选。详情仅作者、参与方式、奖励类型、库存／参与数量、生命周期、开奖状态和关联付款。

用户支持用户名、显示名称、Linux DO ID／本站 ID，普通／青春版及可用状态筛选；详情仅公开身份、永久资格、可用状态、创建／最近登录、发起／领取／报名／商户数量，关联到用户筛选的活动或付款列表。

付款支持任务 ID、业务号、外部交易号，以及活动、商户、收款人、真实／模拟、状态／异常筛选。独立白名单投影展示金额、关联对象、稳定收款人 ID、订单用户名快照（与当前用户名分开）、状态／原因、未知结果、订单证据、发送／查单次数、下一计划和分页结构化尝试。不得复用解密诊断的作者详情。刷新不查外部订单。

## 网站设置与操作记录

保留原登录开关和尝试间隔 GET/PATCH 契约、CSRF、CAS 和关闭 LiteAUTH 时删除未消费 OAuth 授权的行为，已有会话保持。两类独立保存。后台读取不覆盖编辑；刷新先确认“刷新会放弃未保存的修改，是否继续？”，成功才重置（同版本也重置），失败／冲突保留。未知保存先读取核对，再允许原版本重试；核对前保持锁定。界面使用“刷新”，展示更新时间、操作者和反馈；版本内部校验。未保存离开覆盖链接、返回与关闭。

操作记录仅合并现有登录开关与尝试间隔变更，支持类型、操作者、日期，展示前后值与时间；不称全站审计，不新增审计表。每来源游标最多取 21 条，按时间／类型／ID 合并。

## 数据与只读边界

新增 GET `/api/admin/overview`、`activities`、`activities/:id`、`users`、`users/:id`、`payments`、`payments/:id`、`audit`。共用契约新增专用类型、过滤和游标校验，普通用户响应保持。参数绑定，固定排序，批量关联，白名单字段；不返回邮箱、会话、口令、奖励、密钥、密文或原始上游响应。仅 D1／展示配置读取，不调用带恢复的公共／作者读取，也不唤醒 DO、Queue、查单、付款、开奖。诊断规则抽取 Worker 模块供 CLI 和后台共用。

缓存按完整会话身份、模块、过滤、对象隔离。退出、账号切换、401/403 即撤下显示、取消请求、清缓存，迟到响应不能回填。

`0026_admin_read_indexes.sql` 仅新增：未删除活动的创建时间／ID；用户同序；付款全站时间、status＋时间、mode＋status＋时间；登录变更时间索引，沿用尝试间隔索引。默认列表、付款常用筛选、审计来源验证 `EXPLAIN QUERY PLAN`，名称包含不承诺免扫描，不新增 FTS 或依赖。
