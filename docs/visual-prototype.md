SVG 红包总览：访问 [本地总览页](http://127.0.0.1:4177/#svg-gallery) 或原型顶部“SVG 红包总览”，可集中查看共享 SVG 渲染器的各类本地样例，按分类对照业务状态、金额、付款、数量隐私、时效与长内容，并切换时区和动画。圆章文字统一按圆心居中。该页不读取真实活动，不生成图片请求记录。

所有即时操作反馈统一显示在触发操作的按钮或菜单项内，覆盖复制、保存、开放、删除、提前结束、刷新、清除图片请求记录、口令验证、商户凭证修复、网站设置及退出失败。成功或明确失败显示短标签，3秒后还原；重复操作从最后一次结果重新计时，各控件独立，切换账号或对象后丢弃迟到反馈。控件从初始状态就为反馈预留尺寸，不追加提示段落、提示行或 toast，不改变文档流。失败完整原因通过原控件的悬停提示及无障碍描述提供。未知结果保留可见的原提交重试入口和输入锁定，不能被3秒计时清除；冷却在提交按钮中显示。字段校验、初次读取失败、付款和报名的持续业务状态继续按各自语义展示。后台自动读取失败保留旧数据及读取时间；手动操作本身不重复产生外部提示。

复制反馈统一放在发起操作的按钮或菜单项上：成功显示“已复制”，3秒后恢复原文，重复点击重新计时；失败在原控件显示“复制失败”。控件保留原有尺寸，不新增成功段落、提示行或 toast，不使页面内容跳动。分享菜单的复制项保持菜单展开，其他菜单操作照常关闭，Esc与外部点击仍可关闭。各控件分别反馈，无障碍名称在反馈期间保留原标签并附加“，已复制”或“，复制失败”；链接、分享文案与单条可见口令的复制内容保持原规则。

即时领取名单仅在开放后120秒以内（含）显示固定秒数，超出后保留绝对时间，并支持“手速王／我焯有桂！”与手气称号在奖励金额左侧紧凑并列；姓名及奖励区保持原行，时间沿用原有次行。样例使用明确且稳定的开放、领取时刻，编辑不改写开放时间。手速称号使用暗底荧光绿，桌面和手机沿用原名单布局；报名和自动开奖名单保留既有时间语义。

名单为宽440px、高不超过 `min(720px, 85dvh)` 的原生模态；手机宽不超过视口减24px。活动标题与页签固定，记录区内部滚动并倒序追加，每批20条；重开或切页签回首批和顶部。没有名单分页。关闭支持Esc、遮罩与回焦，内部帮助和用户资料留在模态Portal中。

## 正式业务接线缺口

本轮未增加或修改业务接口。现有 API 支持 20 条游标分页（`items` / `nextCursor`）及受版本和责任检查保护的草稿删除，但仍需核对或补充：

| 范围 | 正式接线前需要处理 |
| --- | --- |
| 我的活动、我的参与、付款列表 | 原型所用部分全列表筛选参数；应在服务端先筛选再分页 |
| 付款活动与目标摘要 | 需活动级列表（含零任务活动）、活动／状态筛选、完整待完成／已确认金额与收款人摘要；活动ID→领取ID→付款任务ID保持稳定关联。用户原型仅展示活动付款；不逐条详情补齐或加载全部生产任务分组 |
| 任意相对开放时长 | 当前生产duration仅固定24小时；原型分钟/小时/天需专门数值契约，从正式开放开始计时，不能伪装成固定duration |
| 私有参与批量摘要 | 实际成功口令、本人领取金额、付款确认状态与confirmedAt、奖励方案及截止时间，不能逐条请求详情补齐 |
| 部分活动摘要 | 固定均分／即时随机等奖励方式标识 |
| 活动页公开奖励概要 | 公开详情目前缺少方案与总奖池；应新增专用公开投影，处理固定均分模糊数量时的金额推算，不能下发作者完整配置 |
| 公共报名名单 | 目前仅有作者 `/api/me/activities/:id/registrations` 查询；需独立的公共报名投影和游标分页，服从名单与字段开关，不能直接暴露作者明细 |
| 公共领取／中奖名单 | 已有每批20条、时间＋ID倒序游标，可追加；仍缺全名单极值和并列人数摘要，不能用已加载部分判称号 |
| 公开字段与确认时间 | 核对服务端名单／数量投影，不能仅前端隐藏；confirmedAt是本站确认上游成功时间，不是到账时间，缺失时不能从其他日期推造 |

现有公开 `deadlineAt`／`draw.deadlineAt`、授权口令列表＋`hiddenCount`＋`canSolve`、名单分页契约可继续复用。占位行无真实槽位映射；倒计时归零不替代服务端活动或开奖状态。

原型在完整的本地虚拟集合中筛选和计算后分页。正式接线不通过加载全部生产记录或逐条详情请求绕过这些缺口。草稿删除保留作者、CSRF、版本、从未开放及无领取／报名／付款责任的真实约束。
