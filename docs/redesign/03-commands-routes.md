# 03 命令与地址

状态：定稿。注册表在 `apps/web/src/lib/commands.ts`，路由在 `apps/web/src/router.tsx`。

## 1 原则

- **地址条显示的就是真实地址**。红包是 `/🧧/<表情码>`，两个结果页是 `/🔑/…` 和 `/💬/…/…`，其他页面是英文的 `/` 命令路径（命名规则见第 7 节）。
- **非红包页都通过命令进入**：在指令框输入 `/` 开头的命令，或点顶栏、用户卡片、起始页里的命令链接。
- **命令的规范写法是英文短词**：它同时是网址路径，不用切换输入法就能敲。中文名称、拼音全拼、拼音首字母都能匹配。

## 3 识别与匹配

**命令前缀**

- 半角 `/`、全角 `／`，以及中文输入法下按 `/` 键打出的 `、`，都表示命令。
- 口令只允许汉字和英文数字，所以命令不会和口令冲突。
- 以 `/` 开头、但能解析成红包地址的输入，按红包跳转，例如 `/🧧/<码>`。

**查询词规范化**

- NFKC 规范化，全角字母转为半角；
- 转小写；
- 去掉空白，以及输入法分隔符 `'` 和 `·`。

**排序**（同分按注册表顺序，最多 8 行）

| 分数 | 条件 |
| --- | --- |
| 100 | 命令名或任一匹配词完全一致 |
| 90 | 命令名以查询词开头 |
| 80 | 某个匹配词以查询词开头 |
| 75 | 中文名以查询词开头 |
| 70 | 中文名包含查询词 |
| 60 | 匹配词包含查询词（查询词至少 2 个字符） |
| 30 | 查询词是英文命令名的子序列（如 `hsty` → history；不对拼音做子序列匹配，以免噪声） |

**空查询与无结果**

- 只输入 `/` 时，列出全部可见命令。
- 没有匹配时显示“没有匹配的命令 · 输入 / 查看全部”，回车不执行。

## 4 交互

- **建议列表**（何时弹出、按键见 [02](02-shell.md) 第 6 节）：每行显示图标、`/命令名`（已输入部分朱红）、中文名，身份不够时带标记，当前行显示 ↵；宽窗口在列表底部提示“↑↓ 选择 · Tab 补全 · ↵ 前往”。Tab 补全命令时把 `、` 改成 `/`。
- **动作按钮**：显示“前往 / 登录”，不受口令冷却影响。
- 命令不记入最近输入。
- **命令链接**：顶栏“发红包”、起始页常用命令、用户卡片列表、`/help` 列表都是真实链接。普通点击执行命令；按住修饰键点击在新标签打开。

## 5 快捷键

| 按键 | 起始页 | 停靠 | 展开 |
| --- | --- | --- | --- |
| ⌘K（苹果设备）/ Ctrl+K（其他） | 聚焦并全选 | 空输入展开（红包页带作用域） | 收回 |
| `/`（焦点不在输入框时） | 输入框为空则填入 `/` 并聚焦，否则聚焦并全选 | 展开并预填 `/`（命令模式） | 重新聚焦 |

- 两个快捷键都阻止浏览器默认行为（Firefox 的 `/` 快速查找、浏览器的 Ctrl+K 搜索）。
- 苹果设备上不绑定 Ctrl+K，它在文本框里是“删除到行尾”。

**红包地址**

- 浏览器地址栏里显示为 `/🧧/🔕🐋…☕`，实际传输为百分号编码（`/%F0%9F%A7%A7/…`）。
- 表情码无效时显示“红包地址不对”。
- 表情码写法不规范时（例如带多余的变体选择符），用替换跳到规范写法。
- `/🧧/<UUID>` 也用替换跳到表情码地址（指令框里粘 UUID 本来就能跳转）。
- 📝 📊 🧾 页同样：写法不规范或用 UUID 时，替换到规范地址。
- 从论坛帖子里复制出来的地址，每个表情都成了 `:名字:`（帖子把表情画成图片，复制的是图片的文字），例如 `/:red_envelope:/:chart_decreasing::window:…:hot_beverage:`。直接打开时先把名字换回表情、替换成规范地址，再进入页面；粘进指令框、在网站管理里搜索也都认。名字和表情的对照在 `packages/contracts/src/forum-emoji.ts`，是 2026-10-18 把全部表情贴进论坛帖子取得的，覆盖表情码的全部 1024 个表情、☕ 和 🖼️。
- 完整路径编码后约 170 个字符，在常见限制之内。

**已停用的旧地址**（用户决定彻底弃用）

- 直接打开 `/activities/<UUID>`、`/e/<表情码>`、生产的站内旧页面（`/account`、`/my/activities`、`/my/claims`、`/my/merchants`、`/my/payments` 及其子页，`/admin/rate-limits`），以及 2d 之前原型用过的 `/redeem/…`、`/topics/…`，都显示“未找到页面”，地址条显示原路径，不做跳转。
- 站内不再生成旧地址。
- 例外：在指令框里粘贴旧格式的完整链接，仍识别为“红包链接”并跳到新地址，免得粘贴旧链接显示成“口令含不可用字符”。

## 7 地址命名规则（2d 定稿）

- 命令页和它下面的页面用英文（就是命令名，如 `/merchant/<编号>`、`/admin/users`）；红包、红包下面的页面和两个结果页用表情。路径见第 6 节。
- 用到的表情 🧧 🔑 💬 📝 📊 🧾 🎲 本身就是表情样式，不需要变体选择符，转发时不会坏（🖼️ 见 [05](05-hongbao.md) 第 6 节）。
- 我的某次领取不单独开页：就是红包页 `/🧧/<码>`，“我的结果”在页面上。
