# 01 功能与界面清单

现有正式应用（`apps/web/src`）的全部页面、弹窗、操作与公共组件。每项给出现状位置、建议优先级与处理方式，供逐项评审；勾选表示已确认。

- **优先级**：P0 直接可见；P1 一步可达（点一次出现）；P2 二步内（菜单、面板或展开后才出现）。
- **处理**：保留（逻辑与交互不变，样式重做）、合并、拆分、删除、待讨论。
- 本清单不改变业务规则；业务事实以 [业务规范](../business-spec-v1.md) 和共享契约为准。
- **2c 已决定**：青春版（LiteAuth 登录、升级、账号类型标签）整体取消；“展示领取名单”开关取消，名单一律公开。下文涉及这两项的条目保留为现状记录，处理方式见 [06 生产改动清单](06-production.md)。

## 0 角色

| 角色 | 能做什么 |
| --- | --- |
| 游客 | 浏览公开活动、活动页、公开名单；用活动 ID / 表情码 / 链接 / 帖子跳转；提交口令前需登录 |
| 青春版（LiteAuth） | 登录、浏览、账号管理；兑奖、报名、发起活动、商户配置需通过官方 Connect 升级 |
| 普通账号（Connect） | 兑奖、报名、验证其他口令、发起活动、商户与付款 |
| 活动作者 | 在自己的活动上：编辑、开放、删除草稿、提前结束、付款记录、尝试统计、完整名单；不能领取自己的活动 |
| 管理员 | 只读运维后台；仅网站设置可写 |

## 12 迁移时的技术约束

- 约 9k 行手写 CSS 没有放进 `@layer`，会压过任何 Tailwind 工具类。迁移时要整体替换，或先以 `layer(legacy)` 引入再逐个删除，不能新旧混用在同一元素上。
- 生产 Tailwind 会扫到原型目录：见 [06](06-production.md) 第 10 节。
- 约 60 个测试文件、近 400 处断言检查尺寸、颜色与字号，改版后需要随之更新。
- 代码依赖的类名、id 与 data 属性（滚动重置选择器、`#main`、`[data-shared-envelope]`、`[data-redemption-part]`、`[data-activity-id]` 等）在迁移时要么保留，要么同步修改依赖它们的逻辑。
- 单包加载：见 [06](06-production.md) 第 5 节。
