# 附带网页：红包页旁边的发红包的人的网页（2026-10-26 定）

发红包的人可以给红包附带一个自己的网页（题目、规则、排行榜……）。红包页上，宽屏时它在红包窗口右边的第二个窗口里，窄屏时在底部的抽屉里；不点就不加载。原型在本机试过（2026-10-26），本文定下正式做法。

状态：已实现（2026-10-26），迁移 0046；发布见 hb-ops 的记录。

## 0 说法

| 说法 | 意思 |
|---|---|
| 附带网页 | 发红包的人给红包填的一个 https 网页地址 |
| 网页窗口 | 宽屏红包页右边显示附带网页的窗口，和红包窗口同一种玻璃窗 |
| 边缘标签 | 网页窗口收起时，红包窗口右边缘露出的竖条“发红包的人的网页” |
| 网页抽屉 | 窄屏红包页底部显示附带网页的抽屉 |
| 布局补间 | 窗口宽度跨过布局变化的宽度时，界面各部分移过去，而不是跳过去 |

## 1 规则

- **谁能附带**：🐟额 PLUS（和站长），同代码判定红包（`transferAccess`）。所有玩法都能附带。
  - 表单里只有能附带的人看得到这一项；草稿里已经填了的，照样显示（好删掉）。
  - 新建、保存草稿时，填了地址却不能附带：接口拒绝（`PAGE_NOT_ALLOWED`）；开关关着：拒绝（`PAGE_PAUSED`）。
  - 已经附带的红包，发红包的人后来没了 PLUS，网页照常显示（同已开放的代码判定红包）。
- **地址**：选填，和代码判定联网的地址同一套规矩（[代码判定 §9](programmable-hongbao-design.md)），只是可以带路径、`?` 和 `#`：
  - 只能 `https://`；不能带用户名、密码和端口；
  - 要写完整的域名，不能写 IP 地址或 localhost；
  - 不能用 linux.do、hb.lafi.sh 和它们的子域名；
  - 最多 500 个字；按 URL 标准写回后保存（比如域名转小写）。
  - 规则写在 `@hb/contracts` 一处，表单和接口共用。
- **开放后不能改**：草稿时随便改、删；开放以后，编辑页里这一项只读，接口拒绝改动（`PAGE_LOCKED`）。地址公开（红包页上谁都看得到）。
- **开关和停用**：
  - 网站管理 · 🐟额设置里有“附带网页”开关，默认关。关着时表单里没有这一项，所有红包页都不显示附带网页（地址还在，打开开关又显示）。
  - 站长可以在网站管理 · 红包里停用某个红包的附带网页（不能恢复）；之后那个红包页不再显示它，发红包的人的编辑页写明已停用。
- **什么时候显示**：开关开着、没被停用、填了地址，且红包页是这个红包（`/🧧/<码>`）的页面。发红包的人的其他页（📝📊🧾）和别的页面都不显示。

## 2 界面

### 2.1 发红包表单

- 更多设置 · 公开一组，“关联帖子”下面加“附带网页”，带 PLUS 标记。输入框 `inputMode="url"`，离开时按 URL 标准整理。
- 开放后只读，说明改成“开放后不能改。”；被站长停用时说明写“站长停用了这个网页，红包页上不再显示。”
- 离开输入框时（和打开已经填了地址的表单时），由服务器请求一次这个网页、看它自己的返回头（2026-10-26，用户在 cc.52dmeme.com 上遇到“拒绝了我们的连接请求”后加）：`Content-Security-Policy` 的 `frame-ancestors` 有就按它（每条都要放行本站），没有才看 `X-Frame-Options`（DENY、SAMEORIGIN 都是不许）。不许本站嵌入时，输入框下面写琥珀色的“这个网站不允许被嵌入，红包页上会显示不出来，只能在新标签页打开。”；只是提醒，照样能保存（对方可能正要改设置）。读不到（连不上、超时 5 秒）时不说什么。

### 2.2 宽屏红包页（窗口宽 ≥ 900、高 ≥ 560）

- 平时：红包窗口和现在一样；右边缘露出边缘标签。
  - 它藏在红包窗口后面，只露出窗口外面那一截：红包窗口里的弹窗、压暗层碰不到它。
  - 布局切换完、模糊退掉以后才从窗口后面滑出来，带一下回弹；指针移上去多探出一点，按下缩一下，点了缩回窗口后面。
- 打开：红包窗口收窄到左边（460 宽，布局随之变成窄布局），网页窗口在右边，两扇窗之间 16 像素，合起来占满桌面宽度，但最宽 1680（比单个红包窗口的 1200 宽，超宽屏上居中，不会拉出很长的窗口；用户定，2026-10-26）。
  - 网页窗口：和红包窗口同样的玻璃窗。标题栏写域名和“发红包的人提供的网页 · 不是本站”，按钮：刷新（加载以后）、在新标签页打开、收窄 / 放宽、隐藏。
  - 中间的把手：两扇窗都到位以后才出现；拖动（或聚焦后按左右方向键）改两边的宽度，红包窗口不窄于 380，网页窗口不窄于 360；拖动时两扇窗都模糊，松手后模糊慢慢退掉。
  - 收窄 / 放宽：网页窗口在最窄（360）和红包窗口 460 之间切换。
  - 隐藏：网页窗口收起，网页不卸载，再打开还是原来的样子。离开红包页也收起。
- 切换布局：两扇窗的宽度在 0.52 秒里移过去，同时各自盖一层模糊（backdrop-filter 的蒙层，最多 12 像素，0.68 秒）；窗口里的各部分按布局补间移过去（2.4）。

### 2.3 窄屏红包页

- 底部是网页抽屉，露出一条（把手和标题栏）；红包窗口到抽屉上沿为止，不被挡住。抽屉底部是直角，贴着屏幕底边。
- 拖标题栏或点上箭头拉满（屏幕高的 92%），上面露出的一条压暗，点它或下箭头收起。拖过一半或甩一下就走完剩下的一段。
- 离开红包页时抽屉滑出屏幕，红包窗口同时长回全高。

### 2.4 布局补间

窗口宽度跨过 640（窄布局）、960、1056（顶栏“发红包”的字）时（打开网页窗口、拖把手、拖浏览器窗口），每次改尺寸都量一次标了 `data-morph` 的部分，跨过的那一帧从上一帧的位置补过去（0.42 秒）：

- 指令框：每帧都在它的位置上（窗口改尺寸时同一帧量、同一帧摆，不落后一帧）；跨过的那一帧里它的位置跳了多少（按前两帧的速度推算该到哪，超出的部分），就从那里补回去，不追着跑；里面的地址换写法时淡入。
- 顶栏按钮（发红包、登录、分享）：按钮面从旧大小变到新大小，字和图标淡入，按钮自己的投影等变完再出来。
- 红包皮：高度补过去；标题一块按中心移，数据行移，数字和小字按大小缩放。下面的内容跟着红包皮走，各段整体移。
- 弹窗（名单、说明、代码……）和账户卡片：宽度真的变（文字跟着换行，不压扁），位置跟着移，中间到底部或反过来。
- 名单的列宽、页面左右边距、口令行、作者工具条、在线人数：过渡或移动。

### 2.5 加载之前

网页窗口和抽屉里先显示说明，不加载：

> 发红包的人的网页
> example.com
> 这是发红包的人提供的网页，不是本站的。加载以后，对方能看到你的 IP 地址和浏览器信息。
> [加载网页]

加载一次以后，这个红包页上一直留着（收起、换宽窄屏不卸载；宽窄屏之间切换会重新加载一次，浏览器挪动嵌入的网页必然重新加载）。

## 3 安全

- iframe：`sandbox="allow-scripts allow-forms allow-same-origin allow-popups allow-popups-to-escape-sandbox"`，没有 `allow-top-navigation`（不能把整页导走）、没有 `allow-modals`、没有 `allow-downloads`；`allow=""`（摄像头、麦克风、定位、支付、剪贴板等都不给）；`referrerpolicy="no-referrer"`（对方不知道是从哪个红包来的，除非地址里自己写了）。
- 本站不听它的 `postMessage`，两边不通信。
- 不点不加载；标题栏一直写着域名和“不是本站”。
- 本站自己的页面不许被别的网站嵌入：所有静态页加 `Content-Security-Policy: frame-ancestors 'self'` 和 `X-Frame-Options: SAMEORIGIN`（`apps/web/public/_headers`）。以后做[发红包链接](balance-design.md)（§18）时，那一页按它的 `origin` 单独放开。
- 很多网站不许被嵌入，网页窗口里会显示浏览器的错误页，看不出来是哪种情况；“在新标签页打开”一直在。

## 4 数据和接口

- 地址存在红包配置 JSON 里：`ActivityInput.pageUrl`（可选；空就不写，同 `humanCheck`）。
- 迁移 0046：
  - `balance_settings.page_enabled`（默认关）；
  - `activities.page_stopped_at`（站长停用的时间，空就是没停用）。
- 红包页数据 `PublicActivity.page`：`{ url, host }` 或 `null`（没填、开关关着、被停用都是 `null`）。发红包的人的 `ManagedActivity.pageStopped`。
- `GET /api/me/balance/hongbao` 多给 `page: true`（PLUS 且开关开着），表单据此显示这一项。
- `POST /api/admin/activities/:id/stop-page`：站长停用（只停有附带网页、还没停用的）。
- `GET /api/me/attached-page/check?url=…`：能附带网页的人用，返回 `{ embeddable: "yes" | "no" | "unknown" }`；跟随跳转（和网页窗口一样），只读返回头，不留内容。
- 🐟额 PLUS 能做的事（`plus-features.ts`）加一行“附带网页”。

## 5 文案

- 表单：标题“附带网页”；说明“选填。红包页旁边会显示这个网页（手机上在底部），比如题目、规则或排行榜。开放后不能改。”
- 网页不许嵌入：“这个网站不允许被嵌入，红包页上会显示不出来，只能在新标签页打开。”
- 地址的问题：只能用 https:// 开头的地址；不能带用户名和密码；不能带端口；不能写 IP 地址；要写完整的域名（比如 example.com）；不能写 localhost；不能用 linux.do 和它的子域名；不能用本站的地址；最多 500 个字；不是有效的地址。
- 接口：`PAGE_NOT_ALLOWED`“开通🐟额 PLUS 才能附带网页。”；`PAGE_PAUSED`“附带网页暂时关闭。”；`PAGE_LOCKED`“开放后不能改附带网页。”
- 红包页：原型里的文字（边缘标签、标题栏、按钮、加载前的说明），见 2.2、2.5。
- 网站管理 · 🐟额设置：开关“附带网页”，说明“PLUS 发红包时可以附带一个网页，显示在红包页旁边。关闭后，已附带的网页也不显示。”
- 网站管理 · 红包：详情里一行“附带网页”（地址；停用后写“…由 站长 停用”），按钮“停用附带网页”；确认弹窗标题“停用「标题」的附带网页？”，正文“停用后，这个红包页不再显示附带的网页，不能恢复。”，按钮“取消”“停用”（同停用代码判定红包）。操作记录写“停用红包「标题」的附带网页”。
- PLUS：“附带网页：在红包页旁边放一个自己的网页”。

## 6 不做

- 网页和红包互相通信（比如网页里直接领红包）。
- 核实网站是谁的。
- 每人一份的网页地址、按领取结果换网页。
