# 附带网页：红包页旁边红包作者的网页（2026-10-26 定）

红包作者可以给红包附带一个自己的网页（题目、规则、排行榜……）。红包页上，宽屏时它在红包窗口右边的第二个窗口里，窄屏时在底部的抽屉里；打开才加载。原型在本机试过（2026-10-26），本文定下正式做法。

状态：已实现（2026-10-26），迁移 0046；发布见 hb-ops 的记录。

## 0 说法

| 说法 | 意思 |
|---|---|
| 附带网页 | 红包作者给红包填的一个 https 网页地址 |
| 网页窗口 | 宽屏红包页右边显示附带网页的窗口，和红包窗口同一种玻璃窗 |
| 网页按钮 | 红包页“分享”下面的“附带网页”按钮，打开和收起附带网页 |
| 网页抽屉 | 窄屏红包页底部显示附带网页的抽屉 |
| 布局补间 | 窗口宽度跨过布局变化的宽度时，界面各部分移过去，而不是跳过去 |

## 1 规则

- **谁能附带**：🐟额 PLUS（和站长），同代码判定红包（`transferAccess`）。所有玩法都能附带。
  - 表单里只有能附带的人看得到这一项；草稿里已经填了的，照样显示（好删掉）。
  - 新建、保存草稿时，填了地址却不能附带：接口拒绝（`PAGE_NOT_ALLOWED`）；开关关着：拒绝（`PAGE_PAUSED`）。
  - 已经附带的红包，红包作者后来没了 PLUS，网页照常显示（同已开放的代码判定红包）。
- **地址**：选填，和代码判定联网的地址同一套规矩（[代码判定 §9](programmable-hongbao-design.md)），只是可以带路径、`?` 和 `#`：
  - 只能 `https://`；不能带用户名、密码和端口；
  - 要写完整的域名，不能写 IP 地址或 localhost；
  - 不能用 linux.do、hb.lafi.sh 和它们的子域名；
  - 最多 500 个字；按 URL 标准写回后保存（比如域名转小写）。
  - 规则写在 `@hb/contracts` 一处，表单和接口共用。
- **开放后不能改**：草稿时随便改、删；开放以后，编辑页里这一项只读，接口拒绝改动（`PAGE_LOCKED`）。地址公开（红包页上谁都看得到）。
- **开关和停用**：
  - 网站管理 · 🐟额设置里有“附带网页”开关，默认关。关着时表单里没有这一项，所有红包页都不显示附带网页（地址还在，打开开关又显示）。
  - 站长可以在网站管理 · 红包里停用某个红包的附带网页（不能恢复）；之后那个红包页不再显示它，红包作者的编辑页写明已停用。
- **什么时候显示**：开关开着、没被停用、填了地址，且红包页是这个红包（`/🧧/<码>`）的页面。红包作者的其他页（📝📊🧾）和别的页面都不显示。

## 2 界面

### 2.1 发红包表单

- 更多设置 · 公开一组，“关联帖子”下面加“附带网页”，带 PLUS 标记。输入框 `inputMode="url"`，离开时按 URL 标准整理。
- 开放后只读，说明改成“开放后不能改。”；被站长停用时说明写“站长停用了这个网页，红包页上不再显示。”
- 离开输入框时（和打开已经填了地址的表单时），由服务器请求一次这个网页、看它自己的返回头（2026-10-26，用户在 cc.52dmeme.com 上遇到“拒绝了我们的连接请求”后加）：`Content-Security-Policy` 的 `frame-ancestors` 有就按它（每条都要放行本站），没有才看 `X-Frame-Options`（DENY、SAMEORIGIN 都是不许）。不许本站嵌入时，输入框下面写琥珀色的“这个网站不允许被嵌入，红包页上会显示不出来，只能在新标签页打开。”；只是提醒，照样能保存（对方可能正要改设置）。读不到（连不上、超时 5 秒）时不说什么。

### 2.2 宽屏红包页（窗口宽 ≥ 900、高 ≥ 560）

- 平时：红包窗口和现在一样。网页按钮在“分享”下面（2026-10-26 用户定，原来红包窗口右边缘外露一个边缘标签，不显眼；放在分享左边会和红包皮上的红包作者撞在一起，所以放下面）：
  - 和分享一样钉在顶栏下面，页面滚到哪都在；窄时两个都只有图标。没有附带网页的红包没有它。
  - 点了打开网页窗口；开着时按钮是按下去的样子，再点就收起（同“隐藏”）。
  - 别的入口：红包皮上的“附带网页”标签和说明里的按钮（2.6）。
- 记住开着（2026-10-26 用户定）：宽屏上网页窗口开着离开、或刷新，下次进这个红包页时直接开着（也就直接加载，这个人打开过）；收起了就不再自动开。只记在这个浏览器里（最近 50 个红包），不发给本站。窄屏的抽屉不记，进来总是横栏。
- 打开：红包窗口收窄到左边（460 宽，布局随之变成窄布局），网页窗口在右边，两扇窗之间 16 像素，合起来占满桌面宽度，但最宽 1680（比单个红包窗口的 1200 宽，超宽屏上居中，不会拉出很长的窗口；用户定，2026-10-26）。
  - 网页窗口：和红包窗口同样的玻璃窗。标题栏和红包窗口的顶栏一样高（64），上下沿对齐：左边红色圆底的地球（和手机抽屉同一个），写“来自 @作者 的红包”（作者的 LINUX DO 用户名）和下面一行域名；按钮：刷新（加载以后）、在新标签页打开、收窄 / 放宽、隐藏。标题栏下面一直有提醒条（2.5）。
  - 中间的把手：两扇窗都到位以后才出现；拖动（或聚焦后按左右方向键）改两边的宽度，红包窗口不窄于 380，网页窗口不窄于 360；拖动时两扇窗都模糊，网页不接指针（不然拖到网页上就断了），松手后模糊慢慢退掉。
  - 拖过头关闭（2026-10-26 用户定）：把手拖过最右端以后还能带着阻力走一点（多拖的 35%，最多 84）；多拖 96 以后把手变红，整个网页窗口盖上一层红色的模糊，中间一个 ×，写“松手关闭网页”“往回拖可以取消”；这时松手就隐藏网页窗口（同“隐藏”，下次打开还是拖之前的宽度），拖动时的模糊不退，接着收起的移动，两扇窗归位以后才退掉（2026-10-26 用户说松手后先清楚再模糊一下不对）；往回拖到 96 以内就撤掉。
  - 收窄 / 放宽：网页窗口在最窄（360）和红包窗口 460 之间切换。
  - 隐藏：网页窗口收起，网页不卸载，再打开还是原来的样子。离开红包页也收起。
- 切换布局：两扇窗的宽度在 0.52 秒里移过去，同时各自盖一层模糊（backdrop-filter 的蒙层，最多 12 像素，0.68 秒）；窗口里的各部分按布局补间移过去（2.4）。

### 2.3 窄屏红包页

- 底部是网页抽屉，露出一条（把手和一条横栏）；红包窗口到抽屉上沿为止，不被挡住。抽屉底部是直角，贴着屏幕底边。
- 露出的横栏要让人看见（2026-10-26 用户说不明显）：左边一个红色圆底的地球，写“上拉查看附带网页”和域名，右边一个上下轻点的上箭头；整条都能点，点了拉满。
  - 进红包页时抽屉从屏幕下面弹上来，带一下回弹；停稳以后整条往上探两下（像被拉了一下），只这一次，碰过就不再探。减少动态效果时都没有。
- 拖横栏或点它拉满（屏幕高的 92%），上面露出的一条压暗，点它或再点横栏都收回去。拖过一半或甩一下就走完剩下的一段。
- 横栏拉满以后还是同一条，只变该变的（2026-10-26 用户说图标变小、域名跳、按钮硬出现、颜色突变）：地球图标和域名不动；域名上面一行从“上拉查看附带网页”滑成“来自 @作者 的红包”（同样的字号和颜色）；箭头翻过来朝下；刷新从 0 宽长出来；下沿的线淡入；下面的提醒条展开。收起时反过来。0.26 秒。
- 红包窗口的弹窗（名单、说明、用户卡片、确认……）或展开的指令框打开时，抽屉滑到屏幕下面让开，红包窗口同时铺到屏幕底（在抽屉后面变，看不见），弹窗自己的压暗层盖满整个屏幕（2026-10-26 用户说压暗没盖住抽屉、抽屉自己模糊了：两层压暗接不成一片）；弹窗关上，抽屉回来（不弹跳），回到位以后红包窗口再缩回抽屉上沿（也在抽屉后面）。
- 离开红包页时抽屉滑出屏幕，红包窗口同时长回全高。

### 2.4 布局补间

窗口宽度跨过 640（窄布局）、960、1056（顶栏“发红包”的字）时（打开网页窗口、拖把手、拖浏览器窗口），每次改尺寸都量一次标了 `data-morph` 的部分，跨过的那一帧从上一帧的位置补过去（0.42 秒）：

- 指令框：每帧都在它的位置上（窗口改尺寸时同一帧量、同一帧摆，不落后一帧）；跨过的那一帧里它的位置跳了多少（按前两帧的速度推算该到哪，超出的部分），就从那里补回去，不追着跑；里面的地址换写法时淡入。
- 顶栏按钮（发红包、登录、分享）：按钮面从旧大小变到新大小，字和图标淡入，按钮自己的投影等变完再出来。
- 红包皮：高度补过去；标题一块按中心移，数据行移，数字和小字按大小缩放。下面的内容跟着红包皮走，各段整体移。
- 弹窗（名单、说明、代码……）和账户卡片：宽度真的变（文字跟着换行，不压扁），位置跟着移，中间到底部或反过来。
- 名单的列宽、页面左右边距、口令行、红包作者工具条、在线人数：过渡或移动。

### 2.5 加载

第一次打开（宽屏打开网页窗口、窄屏拉满抽屉）就加载，不再先问（2026-10-26 用户定）；只是看红包页、抽屉还露着一条时不加载，对方不知道有人来过。提醒放在标题栏下面的琥珀色提醒条里，一直在（手机抽屉拉满时）：“不是红包站的网页，它能看到你的 IP 和浏览器信息。不要在里面付款、转账或做任何交易；发现违规推广，请联系站长 @lafish。”（2026-10-26 用户定：说清是红包站、来自谁的红包、不要交易、找谁举报；@lafish 链到站长的 LINUX DO 主页）。是谁的红包写在标题栏里。加载完之前窗口里转一个小圈。

加载一次以后，这个红包页上一直留着（收起、换宽窄屏不卸载；宽窄屏之间切换会重新加载一次，浏览器挪动嵌入的网页必然重新加载）。

### 2.6 别的入口

- 红包皮上的标签最后一个：“附带网页”（地球图标，同“来自帖子”的样子），点了打开网页窗口，窄屏拉满抽屉。
- 说明（附言、结束说明同样）里写 `[文字](#附带网页)`，显示成一个按钮（地球图标和文字），点了同上。没有附带网页（没填、开关关着、被停用）时只显示文字。发红包表单的预览里也画成按钮的样子。
  - 填了附带网页（地址有效、没被停用）时，表单里这三段文字的“原文 / 预览”右边有“插入网页按钮”（2026-10-26 用户要）：在光标处（还没点进去过就在最后）插入 `[打开网页](#附带网页)`；选中了一段文字（一行，不带方括号）就用它当按钮上的字；插入后按钮上的字是选中的，直接打字就换掉；撤销能撤回。在预览里点会先切回原文。

## 3 安全和能力

按宽松的来（2026-10-26 用户定：方便开发者自行接入、二次开发）：不会伤到本站和看的人的能力都给，只挡会被拿来骗人的。

- **给**（iframe 的 `sandbox` 和 `allow`）：运行脚本、提交表单、保留自己的来源（`allow-same-origin`，有自己的 Cookie 和存储）、开新窗口（`allow-popups`，新窗口不受沙箱限制，用来登录）、自己的提示框（`allow-modals`）、下载（`allow-downloads`）、锁定指针和屏幕方向（游戏）、演示、点击后申请自己的 Cookie（`allow-storage-access-by-user-activation`，即 Storage Access API）；全屏、写剪贴板、自动播放、加密媒体、画中画、系统分享、屏幕常亮、手柄。
- **不给**：
  - 把整个红包页导走（没有 `allow-top-navigation` 的任何一种）：嵌入的网页不能把看的人带到一个假的红包站。
  - 摄像头、麦克风、定位、支付、读剪贴板、USB 之类：浏览器问权限时写的是红包站的名字，看的人会以为是本站要的。
- **来源**：`referrerpolicy="no-referrer-when-downgrade"`，网页能从 `Referer` 和 `document.referrer` 知道自己在哪个红包页里（`https://hb.lafi.sh/🧧/<码>`）。红包页地址本来就公开，里面没有口令。
- 本站不听它的 `postMessage`，两边不通信。
- 不打开不加载；标题栏一直写着来自谁的红包和域名，下面的提醒条说不是红包站的网页、不要交易、找站长举报。
- 本站自己的页面不许被别的网站嵌入：所有静态页加 `Content-Security-Policy: frame-ancestors 'self'` 和 `X-Frame-Options: SAMEORIGIN`（`apps/web/asset-cache.ts` 写进 `_headers`）。以后做[发红包链接](balance-design.md)（§18）时，那一页按它的 `origin` 单独放开。
- 很多网站不许被嵌入，网页窗口里会显示浏览器的错误页；表单里会先提醒（2.1），“在新标签页打开”一直在。

### 3.1 给接入的开发者

- **允许被嵌入**：返回头里 `frame-ancestors` 写上 `https://hb.lafi.sh`（试用时再加 `https://staging.hb.lafi.sh`），或者不发 `frame-ancestors` 和 `X-Frame-Options`。
- **知道自己在哪个红包里**：读 `document.referrer`；也可以在附带的地址里自己带参数（`https://example.com/?hb=…`）。
- **登录态**：嵌在红包页里时，网页对浏览器来说是第三方，单独打开时的登录 Cookie 默认带不进来：
  - Chrome、Edge 只发 `SameSite=None; Secure` 的 Cookie；Safari 默认不发第三方 Cookie；Firefox 给每个顶层网站一份单独的 Cookie。
  - 要用已有的登录：在网页里放一个按钮，点击时调用 `document.requestStorageAccess()`，浏览器问过看的人以后，就能用单独打开时的 Cookie。可以先用 `document.hasStorageAccess()` 判断要不要显示这个按钮。
  - 或者在窗口里单独登录一次：登录 Cookie 设 `SameSite=None; Secure; Partitioned`，只在红包站这个窗口里有效。
  - 登录页本身常常不许被嵌入（比如 linux.do），在窗口里登录请用 `window.open` 开新窗口，登录完再回到窗口。
- WebSocket 和 `fetch` 带不带 Cookie，跟上面同一套规则。

## 4 数据和接口

- 地址存在红包配置 JSON 里：`ActivityInput.pageUrl`（可选；空就不写，同 `humanCheck`）。
- 迁移 0046：
  - `balance_settings.page_enabled`（默认关）；
  - `activities.page_stopped_at`（站长停用的时间，空就是没停用）。
- 红包页数据 `PublicActivity.page`：`{ url, host }` 或 `null`（没填、开关关着、被停用都是 `null`）。红包作者的 `ManagedActivity.pageStopped`。
- `GET /api/me/balance/hongbao` 多给 `page: true`（PLUS 且开关开着），表单据此显示这一项。
- `POST /api/admin/activities/:id/stop-page`：站长停用（只停有附带网页、还没停用的）。
- `GET /api/me/attached-page/check?url=…`：能附带网页的人用，返回 `{ embeddable: "yes" | "no" | "unknown" }`；跟随跳转（和网页窗口一样），只读返回头，不留内容。
- 🐟额 PLUS 能做的事（`plus-features.ts`）加一行“附带网页”。

## 5 文案

- 表单：标题“附带网页”；说明“选填。红包页旁边会显示这个网页（手机上在底部），比如题目、规则或排行榜。开放后不能改。说明里写 `[文字](#附带网页)` 会显示成打开它的按钮。”（开放后是“开放后不能改。说明里写 …”）
- 网页不许嵌入：“这个网站不允许被嵌入，红包页上会显示不出来，只能在新标签页打开。”
- 地址的问题：只能用 https:// 开头的地址；不能带用户名和密码；不能带端口；不能写 IP 地址；要写完整的域名（比如 example.com）；不能写 localhost；不能用 linux.do 和它的子域名；不能用本站的地址；最多 500 个字；不是有效的地址。
- 接口：`PAGE_NOT_ALLOWED`“开通🐟额 PLUS 才能附带网页。”；`PAGE_PAUSED`“附带网页暂时关闭。”；`PAGE_LOCKED`“开放后不能改附带网页。”
- 红包页：
  - 网页按钮和红包皮标签都是“附带网页”（这个网页只有这一个名字，2026-10-26 用户定），网页按钮悬停“打开附带网页”“收起附带网页”；
