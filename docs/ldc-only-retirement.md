# LDC 单一奖励与文本奖励退役

## 已确认范围

本次应用只保留固定、自定义、随机金额和限时开奖 LDC 奖励。删除文本 / CDK 的创建、编辑、领取、结果展示、私有读取、后台恢复与原型场景。活动说明、口令、奖励附言、结束说明和分享文案保留。

存量文本活动及关联数据原样保留，不删除、不转成 LDC、不补写结束或失败状态，不提供历史读取兼容。SQL 可以用类型及关联键排除存量；应用不能加载、解析或解密退役奖励。数据库 schema、历史迁移、库存结构、共享加密和已保存开奖计划格式不变，不新增迁移、API 或依赖。

LiteAUTH 登录、青春版身份及官方升级保留。青春版可浏览和跳转，创建、兑奖和报名需要官方普通资格；升级后由用户主动提交。

## 清理顺序与行为锁定

1. 先运行已有 LDC 核心回归；增加隔离数据库旧文本负面样本，锁定数据摘要、未找到响应、无解密和无任务投递。
2. 收窄输入与返回契约为 LDC；保留既有 LDC 解析、默认值、幂等摘要与原编号重试。
3. 以 SQL 的 LDC 条件封闭公共、作者、管理员、历史、统计、发现和所有写入；内部 DO、alarm、Cron、恢复和事务边界使用同一条件。
4. 删除正式与原型的文本专用表单、类型切换、库存、结果、红包、复制、作者名单、筛选、样式和缓存分支。
5. 旧筛选 URL replace 规范化并重置分页；导航存储与 history.state 弹窗版本一起升级。退役资源清理关联展示与意图，其他未确认 LDC 提交保留。
6. 通用测试样本改为本地模拟 LDC，保留非类型专属断言；完成全套检查与当前规范同步。

旧文本默认值、跨类型回退与旧奖励展示兼容属于本次删除范围。LDC 四种金额草稿、未知结果原单重试、旧 LDC 输入规范化、口令历史回填及公开弹窗恢复属于有业务依据的兼容，继续由回归保护。

## 验收边界

- 退役活动的详情、名单、领奖、编辑、口令、统计和管理员资源在既有身份校验后按未找到处理；列表、总数与分页仅计算 LDC。
- 对旧文本活动、口令、库存、领取、提交和尝试记录逐行摘要，执行路由、原编号重试、内部刷新和后台扫描后保持一致。
- 新全站匹配只产生 LDC；旧混合快照不改原候选，原 multiple 不自动降为 single；旧文本目标不能改绑，原 LDC 目标继续使用原提交和订单身份。
- 1440px、375px 检查布局、键盘、名单、长内容和转场；不运行或保存截图。
- 完整领取、开奖、付款和 Queue 闭环只在本地协议替身环境验收。远程验收说明改用关闭资金的 LDC 草稿与资格／开放限制，不新增远程模拟入口。
