## Chrome 本地联调

使用真实 Connect 会话，仅创建本地虚拟活动和模拟奖励，没有外部资金请求。

1. 两个相同口令的文本活动 A、B 均出现在首页结果中；点击卡片进入页面时两者数据库领取数仍为零。
2. 显式领取 B 后得到虚拟文本、活动领完结束；返回原列表，B 显示已结束且本人已领取，A 保持进行中。
3. 只有 A 开启广场；广场只展示 A，帖子索引同时展示 A、B。论坛链接只解析，不抓取或修改帖子。
4. 原强制专属活动统计显示两次尝试、一名账号、一次成功，错误与正确原文历史均可查看。
5. 新建 Chrome 模拟商户，创建并开放 0.06 LDC／三份固定活动；作者页面明确拒绝自领。
6. 通过开发样例工具创建独立虚拟作者后，真实登录用户领取固定活动 0.02 LDC，Queue 自动完成，一次发送、一笔模拟订单。
7. 自定义活动按顺序分配 0.01 LDC，模拟响应丢失／查单不可用后显示核对中；恢复正常场景后自动确认。数据库核对始终一笔订单、一次发送，解除未知标记及商户占用，金额未变。

页面证据位于 `.wrangler/verification/step4-matches-chrome.png`、`step6-fixed-chrome.png`、`step6-reconciling-chrome.png`、`step6-recovered-chrome.png`，均为当前本地页面截图。该目录被 Git 忽略。
