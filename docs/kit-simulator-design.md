# 开发包的模拟器和截图命令

2026-11-01 用户问是不是应该给开发者一个完整的开发套件，比如带红包页布局和功能的模拟器。看过三条路以后用户定：

- 开发者现在都用 AI 写代码，所以本地模拟器（第 2、3 节）和给 Agent 的截图命令（第 4 节）都做；
- 模拟器只要布局、组件和提示大致对得上（宽屏和手机），不做动画；
- 网站上的测试红包不做。

## 1 现在有什么

`npm run page`（[judge-page-design](judge-page-design.md) 11.10）：左边一列简化的假红包页（换人、红包状态、指令框、动态、我的记录、日志），右边是开发者的网页；提交交给本地的 `judge.js`，能模拟冷却、没登录、许可和身份令牌。

缺的：网页在真实容器里的样子（宽屏旁边的窗口、手机底部的抽屉）、红包皮和说明里的按钮、自动打开、几个人同时玩、红包结束；Agent 看不到画面。

## 2 模拟器

`npm run page` 打开的页面换成模拟器，还是一个 HTML 文件、不用构建，全部自己写（开发包是 MIT 许可，不搬网站的代码）。顶上一条工具栏：布局（宽屏、手机、多人）、玩家、重新开始、快进到截止、日志。

**宽屏**：和网站一样，左边红包窗口（460 宽），右边网页窗口。网页窗口的标题栏写“来自 @作者 的红包”和域名，按钮有刷新、隐藏。

**手机**：390×844 的框。红包窗口在上面，底部露出一条“上拉查看附带网页”和域名，点了拉起到屏幕高的九成，标题栏写“来自 @作者 的红包”，按钮“收起”。

**多人**：并排 2–4 个手机框，每个是不同的玩家（`simulate.json` 里的人），一个人提交以后，所有人那边的红包、公开数据、动态都跟着更新，`others` 改到的人的待结算和只给他看的数据也跟着变。框太多放不下时整体缩小。

**红包窗口里**（大致对上真实页面，不做动画）：

- 红包皮：标题、“@作者 的红包”、说明。说明按网站的写法：一个回车换行，`[文字](#附带网页)` 画成按钮，点了打开网页；超过 4 行折起来，下面一个“展开”。这样按钮放在说明最后会被折住，一眼就看得到。
- 两格：“奖池还剩 70%”（下面 0.70 LDC）、“已判定 N 次”；下面一行截止时间或“已结束”。
- 印章“开”：点了打开指令框。指令框里是领取提示（`hongbao.prompt`）和“领取”按钮，冷却时按钮写“还需等待 N 秒”，判定时写“正在判定…”。
- 指令框下面：红包状态（公开数据的一句话和最新一条动态）、我的记录（“第 N 次 · 时间”，结果写“没领到”“+0.50 → 1.20”“结算 1.20 LDC”，下面是判定器的回复和输入）。
- 红包皮下面：只给他看的数据（`player.view.summary`），待结算“待结算 0.30 LDC · 判定器结算或红包结束时发”。
- 结束以后：“判定器结束了这个红包”或“红包已结束”，下面列出每个人结算了多少。

**网页窗口和提示**（用网站上的原话）：

- 第一次打开网页，窗口里先写“打开附带网页？”，按钮“收起”“打开”（[attached-page-design](attached-page-design.md) 2.5）。
- 判定器写了 `pageAutoOpen` 就一进来打开（宽屏打开窗口，手机拉起抽屉）。
- 网页第一次 `hb.submit()` 或 `hb.identity()`：弹“让这个网页知道你是谁、替你提交？”（[page-identity-design](page-identity-design.md) 第 3 节）。
- 没登录的人：`hb.login()` 弹一张模拟的登录卡片，写“这是模拟器：在上面的“玩家”里换一个人，就是登录了”。
- 指令框的提示：“红包已结束。”“你已领过这个红包。”“判定器出错了，这次没有判定，可以再提交一次。”“判定器连续出错，暂停领取”，冷却写在按钮上。

**快进到截止**：把红包的时钟拨到截止时间，还没结算的人一起结算，同 `npm run simulate` 的最后一步。

日志照旧在底部，能收起。

## 3 地址参数

模拟器的地址可以带参数，截图命令和 Agent 都用它直接打开某个样子：

- `layout=wide`、`layout=phone`、`layout=multi`；
- `players=3`（多人时几个框）；
- `who=小明`（单人时是谁）；
- `open=1`（一进来就打开网页，不管判定器写没写 `pageAutoOpen`），`open=0`（不打开）；
- `accept=1`（当作“打开附带网页？”已经确认过，截图时用）。

## 4 截图命令

`npm run page -- --shot`：不开浏览器窗口，在后台打开模拟器，截三张图，存到 `shots/`：

- `wide.png`：宽屏，网页窗口打开；
- `phone.png`：手机，抽屉露一条；
- `phone-open.png`：手机，抽屉拉起。

再写一份文字报告：

- 网页接上 SDK 没有（`hb.ready()` 回来了没有）；
- 网页里的报错（`console.error` 和没接住的异常），每条写出来源；
- 加载失败的请求（网页、图片、脚本）。

有问题时退出码不是 0，Agent 能据此判断要不要接着改。没接上 SDK 只写一行提醒、不算问题（不用 SDK 的网页也可以）。`shots/` 写进开发包的 `.gitignore`。`npm run page -- --shot --play` 先按 `simulate.json` 让里面的人提交完再截图，看玩到一半的样子。

**浏览器**：用开发包新加的 `playwright-core`（只是驱动，几 MB，不带浏览器），先找这台机器上的 Chrome，再找 Edge，再找 Playwright 下载过的 Chromium；都没有就提示运行 `npx playwright install chromium`（约 150 MB），开发包默认不下载。
