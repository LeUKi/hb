# 领取范围（2026-10-22 定）

发红包的人可以限定谁能领：按 LINUX DO 信任等级，或者指定几个人。它是红包的一个设置，和人数、截止时间一样，不是一种新玩法；限时开奖里叫“报名范围”。没有站长级的全站名单（用户定）。

## 0 说法

| 说法 | 意思 |
|---|---|
| 领取范围 | 红包的一个设置：所有人（默认），或者限定。限时开奖写“报名范围” |
| 等级 | LINUX DO 信任等级 Lv0–Lv4，登录时从 Connect 拿到 |
| 指定的人 | 发红包的人填的 LINUX DO 用户名 |
| 仅限 | 红包皮和卡片上的标签都以“仅限”开头 |

## 1 规则

- 限定时有两项，都是选填，至少选一项：
  - **按等级**：一个 Lv0–Lv4 的双头滑条，选出一段（比如 Lv2–Lv4）。两头拉满等于不限，这时这一项不能选。
  - **指定的人**：一串 LINUX DO 用户名，最多 100 个。
- 两项都选时，**满足任意一项就能领**（用户定，2026-10-22）。界面上写成一句话，不让人误会成“两项都要满足”，例如“Lv2 及以上的人，或下面这 3 位，都能领”。
- 开放后不能改，和金额一样。限时开奖要是能在截止前改，就能把已经报名的人挤出去，开奖证明就没意义了。
- 发红包的人自己本来就不能领，不受影响。

## 2 等级从哪来

- Connect 的用户信息（`https://connect.linux.do/api/user`）带 `trust_level`（0–4）和 `silenced`。以前登录时没存（2026-10-22 用户：应该保留好用户数据），从这次起每次登录都存下等级、禁言状态和取得的时间。
- 等级按“上次登录时”算，不实时：本站不保存 Connect 的令牌，没法替人去查（用户接受）。
- 现有的用户在下次登录前没有等级。没有等级的人不算在任何等级范围里，可以按用户名被指定。

## 3 用户名怎么认人

- 保存时，来过本站的人按 LINUX DO 数字 ID 记（改名也认得）；没来过的按用户名记，领取时按当时的用户名对（用户定，2026-10-22）。没来过的人在领取前改了名，就对不上了。
- 用户名不分大小写，重复的只留一个。

## 4 领取、报名

- 服务器在领取和报名时先查范围，再核对口令；不在范围里的不核对口令、不计入尝试统计、不占尝试间隔。返回“不在领取范围里”。
- 页面上，不在范围里的人点印章时直接弹提示，不发请求；首页输入口令匹配到这种红包的，进到红包页领取时同样弹提示。
- 开奖证明不受影响：不能报名的人本来就不在名单里。

## 5 界面

- **发红包**：“更多设置”里一项“领取范围”（限时开奖写“报名范围”），两个选择卡片“所有人 / 限定”，默认所有人。选了限定，下面两项：
  - “按等级”开关，打开后是双头滑条，刻度 Lv0–Lv4，上面写选中的范围（“Lv2 及以上”“Lv1–Lv3”“只有 Lv0”）；
  - “指定的人”：输入用户名、回车或点“添加”加一个；下面一行和转账、邀请一样显示对方（头像、昵称、@用户名），没来过的写“这个人还没来过本站，按用户名认”；加进来的是一排小标签，带头像，可以删；
  - 最下面一句话总结范围，两项都有时明确写“或”：“Lv2 及以上的人，或下面这 3 位，都能领。”
- **找人的组件和接口复用**：转账、邀请、通用链接“以谁的名义”和这里共用一个按用户名找人的接口和一个显示对方的组件（头像、昵称、@用户名，没来过时的那句提示各自说）。
- **红包皮**：“无需口令 / 口令红包”那排标签里加一个“仅限 …”，悬停说明完整范围：
  - 只有等级：“仅限 Lv2 及以上”“仅限 Lv1–3”“仅限 Lv0”；
  - 只有人：“仅限指定的 3 人”；
  - 都有：“仅限 Lv2 及以上或指定的 3 人”。
- **红包广场的卡片**：标签行加同样的“仅限 …”。
- **不在范围里的人点印章**：弹出提示（叠层），标题“这个红包只有部分人能领”（限时开奖写“报名”），正文：
  - “满足任意一项就能领：”，下面列出等级范围和指定的人（列出具体用户名，带头像；用户定），只有一项时不写“任意一项”；
  - 下面写他自己：“你是 Lv1（按你上次登录时）”，没有等级时写“还不知道你的等级，重新登录一次就能更新”；
  - 按钮“知道了”，没有等级或可能过时时多一个“重新登录”。
- 游客点印章照旧先登录，登录后再判断。
- 内嵌图暂不显示范围。

## 6 数据

- `users` 加 `trust_level`（0–4，可空）、`silenced`（可空）和 `profile_seen_at`（这两项取得的时间）。
- 红包的设置（`config`）里加 `scope`：`{ levels?: { min, max }, users?: [{ username, linuxDoId | null }] }`，没有就是所有人。
- 公开读取带 `scope`（等级范围、指定的人的用户名、昵称、头像），会话带当前用户的等级和取得时间。
