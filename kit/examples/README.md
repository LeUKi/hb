# 判定器例子

六个带参数的判定器，判定器广场第一批站长精选就是它们。每个目录一份 `judge.js` 和 `tests.json`，都能跑通 `npm test` 和 `npm run check`。

| 目录 | 名字 | 玩法 |
| --- | --- | --- |
| `guess-number` | 猜数字 | 猜 1 到最大值之间的整数，猜中的领一份；答案保密，每人限次数 |
| `quiz` | 答题 | 一张题目和答案的表，每人抽一道，答对的领 |
| `daily-question` | 每日一题 | 一天一道题，当天答对的领，每天有名额 |
| `by-level` | 按等级发 | 按信任等级发不同的金额，可以再加一个口令 |
| `first-correct` | 前 N 个答对的 | 前几个答对的拿大份，之后答对的拼手气 |
| `timed-password` | 限时口令 | 口令按时间轮换，只有当时的口令算数 |

想在本地改一个：把它的 `judge.js` 和 `tests.json` 复制到开发包根目录（换掉原来的），再把 `judge.js` 里的 `import("../../judge")` 改成 `import("./judge")`（只影响编辑器里的类型提示）。参数怎么写见 `AGENTS.md` 的“参数”。

## 带附带网页的例子

判定器加一个网页（`page/index.html`），网页通过红包站的 SDK 读公开数据、替人提交。在开发包根目录运行 `npm run page -- examples/number-bomb`（或 `examples/scratch-card`），在本地打开假红包页看效果。

| 目录 | 名字 | 玩法 |
| --- | --- | --- |
| `number-bomb` | 数字炸弹 | 1 到最大里埋一颗炸弹，大家轮流猜，猜过的数和安全区间公开；踩中的领一份，接着埋下一颗；网页是一排数字格子 |
| `scratch-card` | 刮刮乐 | 5×5 的卡，份数个格子有奖（金额开放时随机分好），每人刮一格；奖刮完就结束，整张卡公开；网页是那张卡 |
